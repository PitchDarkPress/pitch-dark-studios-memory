THE CODE LOCKER

This folder holds finished and in-progress code for InkySwot —
working files kept safe and findable, separate from the notes
(.md decision and planning files in the repo root).

WHY IT EXISTS

The .md files are the notes — decisions, plans, the build list.
This folder is the code those notes refer to.
When a screen or tool is built as a standalone mockup before being
folded into the app, its finished file lives here so it can be
opened, checked, or pulled down at any time.

HOW TO USE IT

Each file is a complete, runnable HTML file unless noted otherwise.
Open any file directly to see the mockup working.
This README is the index — every file in the locker is listed below
with what it is and where it stands.
Update this README whenever a file is added, changed, or integrated.

CONTENTS

treatment-wheel.html
What it is: The Treatment — the live design source. The WP as a real
document page shifted RIGHT; THE WHEEL out in the dark to its right
(an eased, windowed belt of section labels with a fixed gold centre
line; the centre label is where you are, lit gold with a single
leader; split bunches with fixed gaps); Overview and Writing Mode
(click the centre or a "click to write" to enter; travel scene-to-
scene by the wheel; drafts remembered; "‹ overview" to leave).
The ENTITY POP-UP on the LEFT: two-step from the nav counts (list →
record); quiet-note grammar in each section's colour; per-field copy
buttons (text only); field dividers; a single scroll; stable (click
to open, ✕ to close) and draggable by its header.
Status: MOCKUP — standalone complete; the live design source for the
writing surface / The Treatment / the DCW (Steps 10, 11, 13, converging).
Built: 4 June 2026 (wheel). Pop-up added 5 June 2026.

home-icons.svg
What it is: The four home-page launchpad icons — clean SVG line art
using stroke="currentColor" so they recolour with Tone. Plot Mapping
(constellation), The Press (printing press), Create First Project
(typewriter), Open Project (drawer-chest).
Status: MOCKUP — awaiting integration into the My Projects screen.
Built: 31 May 2026.

map-plotter.html
What it is: The Plot Mapping screen — the story corkboard.
Notes for chapters, characters, locations, plot threads, events,
objects and subplots; drag-to-connect threads; a chapter timeline;
note tabs that flip to a private "Dark Thoughts" back (red full-stop
tells you a note is hiding something); copy system for placing one
beat in several chapters (front shared, each back its own);
chapter-divider toggles; the SECTION ? help-pill pattern.
Status: ARCHIVED — superseded as a build target by the 4 June model.
Plot Mapping the tool is still locked and wanted; the QUIET-NOTE
grammar and Dark Thoughts survive (now in the pop-up). This particular
mockup file is kept as history, not a build target. The note-card face
(tab / knot / full-stop / flip) is superseded.
Built: 30 May 2026. Archived: 4 June 2026.

dcw-vertical.html
What it is: The vertical DCW board (scenes/chapters down a left spine,
tracks as columns) inside the shutter frame.
Status: ARCHIVED — superseded by the 4 June model (InkySwot IS the DCW
/ The Treatment / the wheel). The shutter, the column board and the
fusion are all gone. Kept only as the record of how we got here.
Built: 2 June 2026. Archived: 4 June 2026.
