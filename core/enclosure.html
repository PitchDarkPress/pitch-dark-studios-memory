Step Two

Import & Split

Paste your current index.html below and press Split. The enclosure carves it into the corridor (the shared shell) and one pocket file per content screen, then writes them all into the repo. It reads your existing screen dividers, so the cut follows lines already in your file. This does not touch your live app anywhere else — it only writes into this rebuild repo.
Writes corridor.html and pockets/ into the repo
Step Three

Stitch

Reads the corridor and every pocket back from the repo, joins them in order, and writes the finished index.html. This is the proof: if the stitched file opens and looks exactly like your app today, the split worked. Run this after every edit to a pocket.
Repository: PitchDarkPress/inkyswot-rebuild  ·  Branch: main
Platform feature

Enable Spell Check

Switches on the browser's built-in spell-check for every text field across the whole platform, in one go. Red underlines appear under misspelled words; right-click to correct, or "Add to dictionary" to ignore a word. It follows the browser's language (British English for UK settings). This edits the corridor for you, so you never touch the big file by hand. Press once. It is safe to press again — it will not add itself twice.
Remember to Stitch afterwards
Platform feature

Read Aloud on Every Field

Adds a small Read button to every written field across the whole platform - the big writing boxes and the short one-line fields alike - so any field a writer fills in can be spoken. It catches fields whenever they appear, not just at load. Dropdowns are left alone. This edits the corridor for you. Press once. It is safe to press again - it will not add itself twice.
Remember to Stitch afterwards
One-time setup

Install to Database

Places a copy of this enclosure into the memory database at core/enclosure.html, so you can reach it from the database menu like the Render Bench. You only need to do this once. If you later change the enclosure, press it again to update the copy in the database.
Installs into: PitchDarkPress/pitch-dark-studios-memory  ·  at core/enclosure.html
