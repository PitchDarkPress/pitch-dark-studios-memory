THE CODE LOCKER
This folder holds finished and in-progress code for InkySwot —
working files kept safe and findable, separate from the notes
(.md decision and planning files in the repo root).

WHY IT EXISTS
The .md files are the notes — decisions, plans, the build list.
This folder is the code those notes refer to.
When a screen or tool is built as a standalone mockup before being
folded into the app, its finished file lives here so it can be
opened, checked, or pulled down at any time.

HOW TO USE IT
Each file is a complete, runnable HTML file unless noted otherwise.
Open any file directly to see the mockup working.
This README is the index — every file in the locker is listed below
with what it is and where it stands.
Update this README whenever a file is added, changed, or integrated.
