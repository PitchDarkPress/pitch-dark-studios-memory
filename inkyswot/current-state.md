WHAT IT IS
A new POCKET (where it sits on the platform is a LATER decision — build the
pocket first). A writer's private SEEDBED for FUTURE-story ideas, separate
from any one project. It grew out of two ideas Kev raised this session; the
FACE-GENERATOR idea was DROPPED (too close to "generative", against
Proauthorism) — but two things from it were KEPT for future.md: (a) richer
CHARACTER fields, and (b) ADA AS CONTINUITY-GUARD ("you've written him with
long hair, but his record says short"). Those are banked, not started.

THE CORE CHARACTER OF IT (settled)
- An idea GROWS. It starts as almost nothing (a title, a line) and fills
  out as the writer develops it. Some stay one-liners forever; others swell
  toward becoming a project. The database must hold BOTH comfortably and let
  an idea move small->big without ever forcing it. It does NOT need to be as
  comprehensive as starting a new project.
- REMEMBER (standing rule for this build): everything on the platform
  eventually becomes POP-UPS. So each idea/card must sit happily as a
  pop-up later — same idiom as the entity pop-ups.

THE LOOK — SETTLED THROUGH THUMBNAILS (the journey, so we don't re-tread)
- Chosen METAPHOR: a physical INDEX-CARD / FILING BOX. (Kev's photos: a
  filing drawer, then a pulled-out hanging-file drawer, then a warm
  AI-generated index-card box that nailed it.)
- Chosen LAYOUT: genre DIVIDERS as TABS across the top; click a tab, that
  section's ideas list below. Writer BUILDS THEIR OWN dividers (names them
  what they like — not fixed to the project genres). An "UNFILED" tab sits
  FIRST for freshly-jotted ideas; you FILE each into a divider when ready
  (a "file ->" chip on an unfiled idea).
- Chosen VIEW: FACE-ON (not the 3/4 angle), for readability. Tabs stand in
  a dark WELL with file edges receding behind; a flat CREAM FRONT CARD lies
  below carrying the readable idea list + FILE buttons; a drawer FACE with a
  brass PULL at the bottom. Tabs coloured (Unfiled grey, then per divider —
  the six track colours are the natural palette).
- RICHNESS: built as a still picture at four levels (plain -> lit ->
  textured -> deep). HONEST LIMIT NAMED: the gorgeous reference was
  AI-GENERATED; hand-built code (needed so it can be clicked and hold real
  data) will NOT reach a true photographic finish. Decision pending on
  which richness level — Kev was still judging when the session paused.
